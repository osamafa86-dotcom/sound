# مقام — استوديو الصوتيات بالذكاء الاصطناعي

منصة عربية لتحويل النص إلى صوت بجودة عالية، وكتابة وتلحين الأغاني حسب المقامات الصوتية العربية بالذكاء الاصطناعي.

> راجع [`PLAN.md`](./PLAN.md) للاطلاع على خطة المشروع الكاملة والمزوّدين المعتمدين ومراحل التنفيذ.

## الأقسام

- **استوديو النص إلى صوت** (`/tts`): أصوات عربية بالفصحى واللهجات مع تحكم كامل بالسرعة والثبات والتعبير.
- **استوديو الأغاني والمقامات** (`/songs`): كتابة الكلمات، اختيار المقام (بياتي، حجاز، راست، صبا...) والأسلوب والآلات، وتوليد أغنية كاملة.
- **مساعد الكلمات والمقامات** (داخل استوديو الأغاني): يؤلّف كلمات من فكرة أو يحسّن كلماتك بأي لهجة، ويقترح المقام الأنسب للمعنى، ويبني البرومبت الموسيقي الاحترافي — مدعوم بـ Claude (أو Gemini كبديل تلقائي).
- **معمل الصوت** (`/voice`): تسجيل داخل المتصفح أو رفع ملف، ثم تفريغ نصي (Scribe)، أو تحويل الأداء لصوت آخر (Speech-to-Speech)، أو استنساخ صوتك بموافقة صريحة ليقرأ أي نص.
- **ذكاء صوتي متراكم** (داخل استوديو TTS): تصميم أصوات عربية جديدة من وصف نصي، وذاكرة نطق تتعلم من تصحيحاتك (كتابةً أو تسجيلاً بصوتك) وتُطبَّق تلقائياً على كل توليد لاحق.
- **لوحة مالك النظام** (`/admin`): لصاحب المنصة وحده — صحة النظام والتكاملات، الاستهلاك والكلفة التقديرية، المستخدمون والأرصدة، المهام، الحدود الحيّة، الأصوات، ومفاتيح طوارئ توقف الإنفاق فوراً.

## تطبيق قابل للتثبيت (PWA)

الموقع يعمل كتطبيق ويب تقدمي: افتحه من موبايلك واختر **إضافة إلى الشاشة الرئيسية**
(أو زر التثبيت في متصفح سطح المكتب) فيُثبَّت بأيقونته واسمه ويفتح بملء الشاشة بلا شريط متصفح.
يشمل ذلك اختصارات مباشرة للأقسام (نص إلى صوت، الأغاني، معمل الصوت)، وصفحة أنيقة عند انقطاع
الاتصال، وتخزيناً مؤقتاً للأصول الثابتة لتسريع الفتح — بينما يبقى التوليد والـ API عبر الشبكة دائماً.

## التقنيات

- Next.js (App Router) + TypeScript + Tailwind CSS — واجهة عربية RTL
- طبقة تجريد للمزوّدين (`src/lib/providers`): ElevenLabs / Azure / Google Lyria / Suno لاحقاً
- وضع تجريبي (Mock) يعمل بدون مفاتيح: يولّد سلّم المقام الحقيقي بأرباع النغمات كملف WAV

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## تفعيل المحركات الفعلية (لاحقاً)

أنشئ ملف `.env.local` وأضف المفاتيح عند توفرها:

```env
ELEVENLABS_API_KEY=...
GEMINI_API_KEY=...
ANTHROPIC_API_KEY=...
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=...
```

## تفعيل الحسابات والمكتبة السحابية (Supabase)

بدون إعداد، تعمل «مكتبتي» محلياً في المتصفح (IndexedDB). للتفعيل السحابي:

1. أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com)
2. نفّذ محتوى [`supabase/schema.sql`](./supabase/schema.sql) في **SQL Editor** (ينشئ جدول التوليدات وحاوية التخزين وسياسات الحماية RLS)
3. أضف إلى `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

فتظهر صفحات الدخول/التسجيل تلقائياً، ويُحفظ كل توليد في مكتبة المستخدم السحابية.

## تفعيل لوحة مالك النظام (`/admin`)

لوحة واحدة تجمع كل خصائص المنصة وتفاصيلها، مغلقة افتراضياً حتى للمسجلين:

```env
OWNER_EMAILS=your@email.com          # بُرُد المالكين، مفصولة بفواصل
```

بلا هذا المتغير لا يوجد مالك إطلاقاً واللوحة ترفض الجميع. صلاحية المالك تُقرأ من
بيئة الخادم لا من قاعدة البيانات، فلا يمكن لأحد أن يمنح نفسه الصلاحية بتعديل صف.
سجّل الدخول بالبريد نفسه (بحساب Supabase) فيظهر رابط **لوحة النظام** في الشريط العلوي.

ما تقدّمه اللوحة:

| التبويب | المحتوى |
|---|---|
| **نظرة عامة** | حالة كل ميزة (حيّة/تجريبية/معطّلة)، المفاتيح الناقصة، بيئة التشغيل والإصدار المنشور، أرقام اليوم والأسبوع |
| **الاستهلاك والكلفة** | سلسلة يومية حتى ٩٠ يوماً، تفصيل كل خدمة بعدد الأحداث وكلفتها التقديرية، أكثر المستخدمين استهلاكاً، ترتيب الأصوات بالتقييم |
| **المستخدمون** | كل حساب مع تاريخه ونشاطه ورصيده، وتعديل الرصيد مباشرة |
| **المهام** | مهام توليد الأغاني بحالتها ومرحلتها وسبب فشلها، وتنظيف المهام القديمة |
| **الحدود** | الحدود المضبوطة مقابل النوافذ المستهلكة الآن، وتصفير أي مفتاح لفك حظر مستخدم |
| **الأصوات** | الكتالوج كاملاً بتغطيته وتوفره، وبنك الأصوات المستنسخة والمصممة |
| **التحكم** | مفاتيح طوارئ حيّة + سجل تدقيق لكل إجراء إداري |

مفاتيح التحكم تسري خلال ثوانٍ على كل نسخ الخادم بلا إعادة نشر:

- **وضع الصيانة** — يوقف كل التوليد المكلف فوراً ويعرض رسالتك للزوار.
- **الوضع التجريبي القسري** — الموقع يعمل كاملاً بمحركات محلية: صفر إنفاق على المزوّدين.
- **إيقاف خدمة بعينها** — أوقف الأغلى وحدها بدل إيقاف الموقع كله.
- **لافتة الموقع** — إعلان أعلى كل الصفحات.

> اللوحة تحتاج `SUPABASE_SERVICE_ROLE_KEY` لعرض بيانات المستخدمين والاستهلاك والمهام،
> وتشغيل القسم 11 من [`supabase/schema.sql`](./supabase/schema.sql) (جدولا الإعدادات والتدقيق).
> بدونهما تظهر أقسام النظام والمفاتيح والكتالوج فقط. ولا تُعرض قيمة أي مفتاح API في أي حال — وجوده فقط.

## النشر على Vercel

1. من [vercel.com](https://vercel.com) اختر **Add New → Project** واستورد مستودع GitHub هذا — يتعرف على Next.js تلقائياً بلا أي إعداد.
2. في **Environment Variables** أضف المفاتيح من `.env.example`، وأهمها للإنتاج:
   - `ELEVENLABS_API_KEY` و`ANTHROPIC_API_KEY` و`GEMINI_API_KEY` (محركات التوليد)
   - `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` (الحسابات والمكتبة)
   - `SUPABASE_SERVICE_ROLE_KEY` — **إلزامي على Vercel**: يشغّل نظام المهام الدائم وتحديد معدل الاستخدام (بيئة Serverless لا تحتفظ بالذاكرة بين الطلبات)
   - `OWNER_EMAILS` — لفتح لوحة مالك النظام على `/admin` (بدونه تبقى مغلقة للجميع)
3. اضغط **Deploy** — كل دفعة لاحقة إلى الفرع الرئيسي تُنشر تلقائياً، وكل فرع يحصل على رابط معاينة.

### ربط نطاق من جودادي

في Vercel: **Settings → Domains → Add** واكتب نطاقك. ثم في لوحة جودادي (DNS Management) أضف السجلين اللذين تعرضهما Vercel — عادةً سجل `A` باسم `@` إلى `76.76.21.21` وسجل `CNAME` باسم `www` إلى `cname.vercel-dns.com` — وتُصدر شهادة HTTPS تلقائياً خلال دقائق.
