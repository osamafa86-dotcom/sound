# مقام — تطبيق الموبايل

تطبيق React Native (Expo SDK 57) لمنصة «مقام». التطبيق واجهة لخادم الموقع نفسه —
كل التوليد والذكاء الاصطناعي يعمل على الخادم المنشور على Vercel، فلا مفاتيح API
داخل التطبيق إطلاقاً.

## ما يقدّمه الإصدار الأول

- **النص إلى صوت**: كتالوج أصوات المنصة كاملاً (مجمّعاً باللهجات ومرتّباً بالتقييم)،
  التحكم بالسرعة، تشغيل ومشاركة الناتج.
- **استوديو الأغاني**: الكلمات، المقامات الثمانية، الأساليب (ومنها القوالب الفلسطينية)،
  الأجواء الجاهزة، لهجة الأداء والمغني، معاينة ٣٠ ثانية أو أغنية كاملة حتى ٣ دقائق،
  مع متابعة مراحل التوليد لحظياً.
- **الإعدادات**: ضبط رابط الخادم مرة واحدة (يُحفظ محلياً) مع فحص اتصال فوري.

## التشغيل للتجربة (Expo Go)

```bash
cd mobile
npm install
npm start
```

امسح رمز QR بتطبيق [Expo Go](https://expo.dev/go) على هاتفك، ثم اضبط رابط الخادم
من شاشة الإعدادات (رابط موقعك المنشور، مثل `my-app.vercel.app`).

يمكن تثبيت الرابط وقت البناء بدل الإدخال اليدوي:

```bash
EXPO_PUBLIC_API_URL=https://your-domain.com npm start
```

## الفحص

```bash
npm run typecheck   # فحص TypeScript
npx expo export --platform android   # تحقق أن التطبيق يُحزَم بلا أخطاء
```

## البناء للمتاجر (لاحقاً — EAS Build)

1. أنشئ حساباً مجانياً على [expo.dev](https://expo.dev) ونفّذ `npx eas init` داخل `mobile/`.
2. `npx eas build --platform android` → ملف AAB جاهز لـ Google Play
   (أو `--profile preview` لملف APK تجربه مباشرة على جهازك).
3. `npx eas build --platform ios` → يتطلب حساب Apple Developer ‏($99/سنة).
4. للنشر: `npx eas submit` يرفع البناء للمتجرين.

المعرّفات مضبوطة مسبقاً في `app.json`: ‏`com.maqam.app` للمنصتين.

## البنية

```
mobile/
├── app/                 شاشات expo-router
│   ├── _layout.tsx      الجذر: RTL + وضع الصوت + Stack
│   └── (tabs)/          التبويبات: الرئيسية، نص إلى صوت، الأغاني، الإعدادات
├── components/          Player (expo-audio) + عناصر الواجهة الموحدة
├── lib/                 api.ts (عقود الخادم)، config.ts (رابط الخادم)، theme.ts، data.ts
└── assets/              الأيقونات المولّدة بهوية المنصة
```
